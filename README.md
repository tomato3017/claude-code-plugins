# tomato-claude-mods

A [Claude Code](https://claude.com/claude-code) plugin marketplace.

## Install

Add the marketplace and install a plugin in one step:

```
/plugin install <plugin> --marketplace tomato3017/tomato-claude-mods
```

Answer `y` to add the marketplace, then choose a scope.

## Plugins

| Plugin | Description |
| --- | --- |
| [radio-multi](plugins/radio-multi) | `/radio-multi` opens a pane of radio stations; the pick opens in your browser |

## Layout

Each plugin lives in `plugins/<name>/` and is listed in `.claude-plugin/marketplace.json`.
